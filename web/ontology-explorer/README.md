# Orus Ontology Explorer

Explorateur visuel borne de l'ontologie materialisee. Le frontend ne connait
ni PostgreSQL ni le moteur Zig : il consomme exclusivement Ontology API v1.

```sh
../../scripts/pilotage.sh setup-web
../../scripts/pilotage.sh web-dev
```

Interface locale : `http://127.0.0.1:5173`.
